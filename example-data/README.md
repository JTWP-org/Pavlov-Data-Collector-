# 🧪 Sanitized JTWP Example Data

This folder is a synthetic example of the JTWP collector data layout.

- All player names and IDs are placeholders.
- Player/network hashes are fake placeholders.
- Public example IP addresses use RFC 5737 documentation space (`203.0.113.0/24`).
- The real `private/` dataset is intentionally omitted because it contains raw IP mappings and is not appropriate for a public example.
- JSONL/log files are not included here because this package focuses on JSON examples.

The layout follows the collector's `global/`, `players/`, and `servers/` datasets.
